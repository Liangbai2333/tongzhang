### 1.2 错误码与文档一致性核对

核对 `A13～A17`、`A31` 全部错误码在服务端实现与 [api-reference.md](api-reference.md#状态冲突与明确恢复) 中的映射：

- `400 VALIDATION_ERROR` / `IMAGE_INVALID`：非本账本成员、分摊不守恒、缺少/非法 UUID 幂等键、空文本且无收据、`A31` 使用已绑定或非 `RECEIPT` 图片，与文档一致。
- `401 UNAUTHENTICATED` / `403 FORBIDDEN`：未登录先返 401；非成员、非记录人/非创建者编辑或删除、使用他人上传收据图返 403，与文档一致。
- `404 NOT_FOUND`：消费不存在或已软删除（换新键再查/再改/再删），与文档一致。
- `409 LEDGER_FROZEN` / `VERSION_CONFLICT` / `IDEMPOTENCY_CONFLICT`：非 `ACTIVE` 写操作及 `A31` 解析返 `LEDGER_FROZEN`；`A16`/`A17` 消费版本过期返 `VERSION_CONFLICT`；同键不同载荷返 `IDEMPOTENCY_CONFLICT`，与文档一致。
- `502 AI_DRAFT_UPSTREAM_ERROR` / `503 AI_DRAFT_UNAVAILABLE`：上游超时、网络异常、非 2xx、非法 JSON、内层残缺 JSON 或二次校验失败返 `502`；`AI_DRAFT_API_BASE_URL` / `AI_DRAFT_API_KEY` / `AI_DRAFT_MODEL` 任一未配置返 `503`，均不写库，与文档一致。
