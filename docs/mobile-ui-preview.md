# 移动端界面预览

本分支初步实现原生移动端页面与本地 UI 交互，尚未接入业务操作。默认启动欢迎页，右上角「界面预览」进入设计样例。登录与注册按钮不会创建会话，也不会跳转成登录成功；预览区始终显示「界面预览 · 示例数据，不会保存」。

## 已实现范围

| 入口 / 路由                        | 页面         | 本批交互                                                          |
| ---------------------------------- | ------------ | ----------------------------------------------------------------- |
| `/`                                | 欢迎         | 开始使用、登录、界面预览导航                                      |
| `/login`、`/register`              | 账号表单     | 输入、焦点描边、密码显隐、协议勾选与阅读面板                      |
| `/preview`                         | 我的账本     | 状态筛选、右上角创建/加入菜单、底部导航                           |

| `/preview/ledger`                  | 鼓山一日详情 | 消费列表、类别/付款人筛选、无匹配状态、成员面板、消费详情简版面板 |
| `/preview/expense`                 | 记一笔       | 金额与名称输入、备注、类别/付款人/日期面板、分摊方式和成员选择    |
| `/preview/balances`                | 成员余额     | 静态余额与进入结算预览                                            |

首批共 13 个产品页面，另保留原有联调页。路由文件只导出页面，页面按业务放在 `src/features/*/screens`。面板、错误和筛选状态都留在当前页面，不建立全屏路由。

## 数据与业务边界

- 预览明确使用 Figma 设计样例，集中金额夹具位于 `src/features/preview/fixtures.ts`。金额格式化沿用 `domain` 的 bigint 整数分工具；没有实现前端结算算法。
- 没有调用登录、创建/加入账本、保存消费、结算、还款或资料更新 API。点击提交只显示尚未接入的提示，不伪造成功反馈或修改业务状态。
- 输入与选择只存在于页面内存，不写入持久化缓存、会话或离线队列。
- 日期目前是输入框；按份/按金额目前只提供方式选择；完整分摊编辑、日期选择器、未保存离开确认和业务校验尚待接入。
- 上传、拍摄、扫码、复制、分享均只提示未接入，不申请相机/相册权限。邀请二维码是 Figma 静态资源，不是有效邀请凭据。
- 周末聚餐、宿舍生活、历史账本目前只有状态样例或说明，未实现独立详情。正式结算进度、还款登记、结清归档与其他异常状态尚未覆盖。
- 账户信息与设置在本批暂以面板预览；正式账户页与设置页可在后续阶段依 Figma 补齐。协议正文尚未接入，面板明确标记为示意。

## 视觉与交互依据

主要依据：[同账 Figma / Screens](https://www.figma.com/design/tngbOd0rJkD29C7Qe2r2zh?node-id=1-3)。首页采用当前文件中的添加菜单版本，优先于原型说明中的旧入口描述。

| 决定                         | 依据                                         | 落地                                                                          |
| ---------------------------- | -------------------------------------------- | ----------------------------------------------------------------------------- |
| 暖白画布、白卡片、杏黄主操作 | Figma 色板与页面上下文                       | `#FAF9F6`、`#FFFFFF`、`#FFC86A`；圆角 12/16/20/24                             |
| 金额优先、语义状态色         | Figma 账本/余额/结算                         | 大字号金额，绿色应收、红色应付，颜色之外保留文字                              |
| 原始图标、插画、环图与二维码 | Figma 节点导出                               | 本地 `assets/figma`，`icons/figma-assets.ts` 记录原始尺寸；不引用临时远程资源 |
| 少量阴影、清楚的按钮层级     | Figma 主导；Refero 的 Apron 与 Zelt 补充参考 | 不改用外部参考的品牌色或网页布局                                              |
| 按压与面板动效               | Refero motion 技能                           | 按压 120ms / 0.98 缩放；面板 280ms 淡入与上移，返回反向播放；页面使用原生转场 |
| 减少动态效果                 | 系统可访问性偏好                             | 禁用缩放、位移与页面动画；保留即时按压反馈                                    |
| 移动端布局                   | Expo SDK 57、React Native                    | 安全区、底部固定操作、滚动内容、键盘避让；不绘制假系统状态栏/手势条           |

Figma 使用 Noto Sans SC，本批采用平台系统字体，未引入字体或原生依赖；中文字形和字重可能有平台差异。欢迎页新增预览入口，预览页新增提示条，因此不宣称整屏像素级一致。

API 参考：[Expo SDK 57 Router](https://docs.expo.dev/versions/v57.0.0/sdk/router/)、[Expo SDK 57 Image](https://docs.expo.dev/versions/v57.0.0/sdk/image/)。

## 验证

已运行：

- `pnpm check`：类型、ESLint 与格式检查通过。
- `pnpm test`：10 个测试文件，36 项既有无数据库测试通过。它们不覆盖本批原生 UI 交互。
- `pnpm export:mobile`：Android / iOS JavaScript 打包通过。
- `pnpm doctor:mobile`：联网重试后 21/21 通过。
- 本地资源核对：导出文件非空、映射尺寸与 SVG 根尺寸一致，运行时代码没有 Figma 临时下载 URL。

原生验收尚未完成：已有开发客户端已安装并启动至 iPhone 17e / iOS 27 模拟器，但系统停在打开确认框；Mac 锁定，用户暂时无法解锁，电脑控制工具不能继续操作。尚未看到本批页面实际渲染，不能据此判断图标、字体、动画或键盘行为已经通过原生验收。未进行真实设备与实际数据库业务验证。

解锁后建议按下列顺序验收：

1. 欢迎→登录/注册：插画、密码显隐、键盘弹出后输入与底部按钮不遮挡；提交不会登录。
2. 界面预览→右上角添加：打开与关闭面板，进入创建与加入；检查返回与退出预览。
3. 鼓山一日→筛选：选餐饮应有一项，选住宿应显示无匹配，重置恢复三项。
4. 记一笔→分摊：取消所有成员后「完成」禁用，关闭面板不会跳成新页面；提交不保存。
5. 余额→统计→结算：核对设计样例金额与图标，确认结算后保持预览，不进入结算中。
6. 我的→设置：通知开关只改变本地 UI；检查大字体、窄屏、系统减少动态效果，以及 Android 返回键关闭面板。
