# 实机多人联调

多人在各自手机上用真实账号走同一个账本：一台电脑作为主机运行数据库、API 和 Metro，手机安装开发客户端后连到这台主机。全部数据在主机的开发数据库里，主机关闭后所有人都无法使用。地址规则见[开发说明](development.md#3-移动端地址与发布配置)，单人完整操作见[操作手册](app-user-guide.md)。

## 1. 主机

在仓库根启动：

```bash
pnpm up:db
pnpm dev
```

API 默认监听 `0.0.0.0:3300`，Metro 监听 8081。把 `apps/mobile/.env` 改为主机局域网 IP（macOS 可用 `ipconfig getifaddr en0` 查看），不带 `/api/v1`：

```text
EXPO_PUBLIC_API_BASE_URL=http://<主机局域网IP>:3300
```

修改后重启 `pnpm dev`。这个地址在 Metro 打包时写入 JS，所有手机连同一个 Metro 就使用同一个 API，不需要每台手机单独配置。

- 主机 IP 变化后，手机会停在「暂时无法核验登录状态」。联调前在路由器为主机保留固定 IP；变化后需要改 `.env` 并重启 `pnpm dev`。
- macOS 首次提示是否允许 node 接受传入连接时选择允许；Windows 需允许 Node 访问专用网络。

## 2. 网络

主机和所有手机连同一个局域网。每台手机先用浏览器打开 `http://<主机IP>:3300/health/live`，能看到返回内容才继续。

校园网、公司网常开启客户端隔离，同一 Wi-Fi 下设备互相访问不到。此时改用一台手机开热点，或者使用自己的路由器，让主机和所有手机都连上去。

## 3. 安装开发客户端

Expo Go 和 JS 导出都不能代替开发客户端。原生依赖、app config 或 config plugin 变化后需要重新安装；只改 JS 时手机重新载入即可。

| 平台    | 安装方式                                                                                                                                                                                                                               |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| iOS     | 用数据线连接装有 Xcode 的 Mac，执行 `pnpm build:ios --device` 并选择这台 iPhone。免费 Apple ID 签名的安装包 7 天后失效，需要重新安装；手机需开启「开发者模式」，并在「设置 → 通用 → VPN 与设备管理」中信任开发者。每台 iPhone 各装一次 |
| Android | 打开 USB 调试后执行 `pnpm build:android --device`；也可以把构建出的 `apps/mobile/android/app/build/outputs/apk/debug/app-debug.apk` 发给成员，用 `adb install` 或直接在手机上安装                                                      |

打开开发客户端后，扫描 Metro 终端显示的二维码，或手动输入 `http://<主机IP>:8081`。真机通过局域网连接时不需要 `adb reverse`；`localhost` 在真机上指手机自身。

## 4. 联调流程

1. 每人在自己的手机上注册账号，用户名尽量便于辨认。
2. 创建者建账，在「邀请成员」中把 6 位邀请码发给其他人。邀请码 7 天有效，每个账本最多 12 人。
3. 其他人在账本列表右上角 + →「加入账本」，输入邀请码，核对名称和创建者后加入。
4. 各自记账，再依次查看余额、结算预览，由创建者发起结算，付款人登记已还，最后创建者结清并各自归档。逐步预期见操作手册的双账号示例。

- 没有实时推送。别人写入后，切换标签、从详情返回或手动下拉时会在线读取最新内容。
- App 从后台回到前台会先在线核验登录状态，主机或网络不通时会被拦在核验界面。
- 分摊、结算、权限都以服务端校验为准，冲突时按界面提示刷新后重试，不要重复提交。

## 5. 不在同一个网络时

局域网方案只适用于同一地点。成员分散在不同地方时，可以选择：

- **隧道**：用 cloudflared、ngrok 等把 API 映射为 HTTPS 地址，写入 `EXPO_PUBLIC_API_BASE_URL`；Metro 使用 `expo start --tunnel`（需要额外安装 `@expo/ngrok`）。主机仍须一直在线，适合临时联调。
- **部署服务器**：按[开发与部署说明](development.md)用 `infra/deploy.sh` 部署，再构建使用 HTTPS API 的 preview 安装包。目前尚未部署生产环境，也未绑定 Expo 项目、签名或执行云构建。
