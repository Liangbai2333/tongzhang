## 参考锁定与取舍

| 决策                   | 设计依据                                               | 实现约束                                                                                                                    |

| 输入与封面预览         | `5:100`                                                | 内容左右 24px，预览使用浅黄底与描边；选项保持可访问选中状态，至少 44px 点击高度                                             |
| 空账本插画             | `17:1015` 及其子节点                                   | 按设计上下文用原生布局组合收据、色块和文字；dots、add、payer、members 等使用原 SVG，装饰不冒充成员或金额                    |
| 图标                   | 上述上下文的原始导出                                   | 本地 SVG 引用，无运行时临时 Figma URL；保留 SVG 根尺寸。资产尺寸与位置记录见 [资产核对](evidence/figma-ledgers/assets.json) |
| 系统区域               | 原生安全区域                                           | 使用真实状态栏、安全区、键盘和系统 Home Indicator，不绘制设计稿中的假系统栏                                                 |

业务数据始终来自 API。画板中的“三本示例账本”、示例余额和成员头像没有复制进 App。列表仍按当前契约显示“待收 / 待付 / 已平衡”与总支出，不把个人净额改称画板中尚未明确接口口径的“当前分摊”。

## 保留的差异与后续范围

- 列表契约没有状态筛选参数、全量分类数量和成员姓名，暂不增加会误导用户的分类计数或头像堆叠；当前显示“全部账本”。已归档入口调用现有 `archived=true` 查询并继续使用服务端游标分页，切回当前列表也重新在线查询。
- 封面保留已支持的四个预设（包括城市），比当前画板多一个选项。山野预览使用设计稿 56px 原资产，其他预设沿用对应本地 SVG 并在 56px 展示区域内缩放。
- 图片上传尚未接通，上传行明确标注“暂未开放”；消费页尚未接通，“记第一笔”保持禁用并说明不可用。
- 当前继续使用平台字体，尚未内置画板中的 Noto Sans SC；本轮对齐字号、行高、字重和层级，不声明跨平台字体像素一致。
- 有消费的详情、邀请/加入页、成员面板及“我的”内容留待后续逐屏对齐。原有真实查询、邀请权限、失败保留输入和幂等逻辑继续保留。

后续进展：邀请/加入页与成员面板已在 [第二轮对齐](figma-invitations-alignment.md) 中实现并单独记录验证；上方结果保留为第一轮历史记录。
