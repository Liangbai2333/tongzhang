## 2. 账号、资料偏好与站内提醒封板一致性核验

| 核对项                     | 实现                                                                                                                                            | 文档                                                              | 结论                                                          |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------- |
| `A28 updateProfile`        | 在线会话；`users FOR UPDATE`；用户名 2～30 字符；同名仍 `200` 并写 `PROFILE_UPDATED` 审计；邮箱只读；不改账本/消费 `version`                    | 接口索引 A28 行与「A28/A29」字段说明一致                          | 一致                                                          |
| `A29 updatePreferences`    | 布尔绝对值写入 `notification_enabled`；同值仍写 `PREFERENCES_UPDATED`；控制催还是否入库，响应不泄露该开关                                       | 接口索引 A29 行、已知限制「资料、偏好与提醒」行一致               | 一致                                                          |
| `A33 listNotifications`    | 仅 `recipient_user_id = principal.userId`；`unreadOnly`；`(created_at, id)` 游标；`repeatable read` 只读事务；实时关联 `actorName`/`ledgerName` | 接口索引 A33 行一致；面板 `staleTime: 0` 与 Day 5 `#154` 加固一致 | 一致                                                          |
| `A34 markNotificationRead` | 非接收人 `403 FORBIDDEN`；不存在 `404 NOT_FOUND`；重复标记保留首次 `readAt` 并写审计                                                            | 接口索引 A34 行与错误码表一致                                     | 一致                                                          |
