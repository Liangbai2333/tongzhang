# 首版业务约束

工程实现以本文件和原型说明为基线，避免早期讨论中的增强项自动进入首版。

| 范围 | 约定                                                               |
| ---- | ------------------------------------------------------------------ |
| 账号 | 真实注册、登录、可续期会话与退出即时撤销；用户名可改，邮箱首版只读 |
| 账本 | 名称、封面、创建者；最多 12 人，包含创建者                         |
| 邀请 | 6 位邀请码 + 应用内扫码；同一邀请记录，7 天有效，重置使旧码失效    |
| 消费 | 标题、金额、类别、日期、付款人、分摊人、备注、最多 1 张收据        |
| 角色 | 记录人、付款人、分摊人分别保存；付款人可以不参与分摊               |
| 分摊 | 人均、按份、按金额；最大余数法，余数相同按稳定成员 ID 分配         |
| 类别 | 餐饮、交通、门票、住宿、购物、其他                                 |
| 金额 | PostgreSQL BIGINT、TypeScript bigint，单位分；JSON 为整数分字符串  |
| 结算 | 净额 + 零和子集 DP，人数上限内精确最少笔数                         |
| 状态 | ACTIVE → SETTLING → SETTLED；预览不冻结，正式结算保存快照并冻结    |
| 已还 | 人工登记，不是真实支付；登记仅影响剩余应收应付                     |
| 结清 | 全部登记且剩余净额为零，由创建者确认；结清后只读                   |
| 归档 | 已结清账本允许个人归档，保存成员 archivedAt，不影响其他人          |
| 在线 | 不支持离线访问、草稿或自动同步；当前表单只保留在内存中供手动重试   |
| 通知 | 仅保存通知开关偏好，具体提醒事件暂不实现                           |

权限：成员可读、可在进行中新增消费；记录人或创建者可编辑/删除；创建者管理邀请、正式结算和结清；转账付款人或创建者登记已还。权限必须在服务器执行。

本阶段不实现真实支付、多币种、OCR、聊天、邀请链接唤起、CSV、预算、行程日、成员移除、撤销还款或取消结算。

验收账目：小安付食堂 ¥120，四人均分；小白付门票 ¥120，四人均分；小陈付车费 ¥60，小安/小陈均分。总消费 ¥300，净额依次 +¥30、+¥60、−¥30、−¥60；转账小陈→小安 ¥30、小丁→小白 ¥60。
