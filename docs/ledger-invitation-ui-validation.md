## 实现与接口依赖

- 登录后进入 `/ledgers`，可在线刷新、按服务端游标加载更多、创建或加入；“我的”保留真实账号和原有协议面板。
- `/ledgers/create` 校验名称和四种预设封面，调用 A05，成功后进入邀请页；自定义图片封面依赖图片模块，当前没有上传入口。
- `/ledgers/[ledgerId]` 使用 A07 的真实总支出、个人金额和成员信息，金额始终由整数分格式化。成员在原页底部面板展示，创建者和本人有文字标识。只有进行中账本的创建者看到邀请管理入口。
- `/ledgers/[ledgerId]/invitation` 在线读取 A07/A09，展示真实账本名、邀请码、有效期和二维码；复制调用系统剪贴板，分享直接调用系统分享；A10 重置前确认，成功才刷新。
- `/invitations/join` 将输入转为大写并校验字符集，A11 只预览账本名、创建者和人数；确认后才调用 A12。已是成员时直接进入；不可加入、人数已满、非法码、过期码和服务端拒绝均在原页或原面板反馈。
- 写操作有同步点击锁、提交中禁用、稳定幂等键，无自动重试或离线队列。结果不确定时锁住原输入，仅允许用户手动重试原提交；同一键最多在首次提交后 24 小时内复用，超过窗口要求先在线核对结果。请求标识和表单仅存于当前组件内存。
- 页面获得焦点时重新查询；加载或读取失败时隐藏原账目，错误状态不另建路由。查询按用户隔离，不持久化缓存；退出沿用已有会话清理。

服务端实现归属 [Issue #14 / PR #21](https://github.com/Liangbai2333/tongzhang/pull/21)。本次以 PR head `7b97e2eb4cbe67a860c72c12d78abd51a0bd99eb` 的归档副本运行隔离 API，没有将其代码混入本分支，也没有合并、提交、推送或关闭任务。主线 Service 仍为 501，必须先合入该依赖才能直接在主线完成同一路径。消费界面、图片上传、扫码加入及个人归档不在本次界面交付内。

## 原生实操与证据

1. 准备已实现 A05–A12 的服务端、专用数据库和 SDK 57 开发客户端，按上面的 API 地址启动 Metro。
2. 甲登录，列表为空；打开创建页，填写名称、选择预设封面，创建。邀请页显示服务端返回的六位码；进入详情，甲是唯一成员。截图：[创建表单](evidence/ledger-invitation/ios-create-form.png)、[真实邀请与复制成功](evidence/ledger-invitation/ios-created-invitation.png)、[创建者成员](evidence/ledger-invitation/ios-creator-member.png)。
3. 甲退出，乙登录。输入不存在但格式合法的 `ZZZZZZ`，服务端报无效；输入已过期的真实邀请，服务端报过期，原输入保留。为复现过期，仅在专用库按本次账本与创建者精确限定修改邀请有效期，测试后恢复。截图：[无效码](evidence/ledger-invitation/ios-invalid-code.png)、[过期码](evidence/ledger-invitation/ios-expired-code.png)。
4. 使用有效邀请预览，此时为 1/12 人；确认后进入同一账本，为 2/12 人。乙不能看到创建者邀请按钮。截图：[加入前预览](evidence/ledger-invitation/ios-join-preview.png)、[乙端成员](evidence/ledger-invitation/ios-joined-members.png)。
5. 终止并重开 App，在线恢复乙的会话，列表仍能查询账本；重新登录甲后，成员面板也显示相同两人。截图：[重开后的在线列表](evidence/ledger-invitation/ios-restored-list.png)、[甲端刷新成员](evidence/ledger-invitation/ios-creator-refreshed-members.png)。两端使用同一台模拟器依次切换账号，未声称双设备同时操作。
6. 临时停止本次 3313 隔离 API，进入账本显示连接失败和手动重试，不展示旧余额；恢复服务后仍停在错误状态，点击重试后才读取成功。打开无成员权限的 UUID 账本，原页显示权限错误并提供返回列表。截图：[真实 API 不可用](evidence/ledger-invitation/ios-api-failure.png)、[无权访问](evidence/ledger-invitation/ios-forbidden.png)。
7. 自动化测试额外覆盖同键重试、24 小时窗口、提交中重复点击及面板关闭、预览取消、满员、预览后加入竞争、重复成员直接进入、复制失败与独立的再次重置。此部分为回调级测试，区别于以上原生与数据库实操。
